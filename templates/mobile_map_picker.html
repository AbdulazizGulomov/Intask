{% load l10n %} {% comment %} Standalone map picker for the mobile "E'lon berish" WebView. No base template, no chrome, no text — just a full-viewport Yandex map with a fixed centre pin (map moves under the pin, same pattern as the web picker). Page → app: on load and whenever the map settles (actionend / boundschange, debounced ~300 ms) it posts {"type":"location","lat":..,"lng":..} via window.ReactNativeWebView.postMessage (console.log fallback on desktop). App → page: window.__fromApp({type:"center",lat,lng}) recenters (zoom 16, short animation); a normal location message follows once settled. {% endcomment %}
