{% trans "Privacy Policy" %}

{% trans "Last updated: 8 August 2026" %}

{% blocktrans trimmed %} This Privacy Policy explains what personal data InTask collects, why we collect it, who we share it with, and how you can delete it. It applies to the intask.uz website and the InTask Android application (package uz.intask.app). {% endblocktrans %}

{% trans "1. What we collect" %}

{% trans "Account data (all users):" %}

  • {% trans "Phone number — used as your login identifier and to send SMS verification codes." %}
  • {% trans "Account role (worker or employer) and registration date." %}

{% trans "Worker profile data (entered by you):" %}

  • {% trans "First name, last name, age and gender." %}
  • {% trans "Profile photo, if you upload one." %}
  • {% trans "Profession and certificate files, if you upload them." %}

{% trans "Job posting data (entered by employers):" %}

  • {% trans "Job title, description, region, pay range and job photos." %}
  • {% trans "A contact phone number, which is displayed publicly on the job page." %}
  • {% trans "The job location as map coordinates. If you use the “get location” button when creating a job, your device's GPS location is read at that moment and stored as the job's coordinates." %}

{% trans "Job applications:" %}

  • {% trans "When a worker applies to a job, we store which worker applied to which job, and the employer can see the worker's profile." %}

{% trans "Verification codes:" %}

  • {% trans "The one-time SMS code is stored on our server for a maximum of 5 minutes and is deleted as soon as it is used or expires." %}

{% blocktrans trimmed %} The “jobs near me” feature and the map on our landing page may ask your browser for your location. That location is used only on your device to centre the map and calculate distances; it is not sent to our server. {% endblocktrans %}

{% trans "2. Why we collect it" %}

  • {% trans "To create and sign in to your account using SMS verification." %}
  • {% trans "To show worker profiles to employers and job postings to workers — this is the core function of the platform." %}
  • {% trans "To show job locations on a map." %}
  • {% trans "To connect workers and employers when a job application is made." %}

{% trans "We do not use advertising or analytics trackers, and we do not sell your data." %}

{% trans "3. Who we share it with" %}

  • {% trans "Eskiz (notify.eskiz.uz) — an SMS provider in Uzbekistan. It receives your phone number and the verification message in order to deliver the SMS code." %}
  • {% trans "Yandex Maps — used to display maps on job pages. When a map loads, Yandex receives standard technical data such as your IP address." %}
  • {% trans "Content delivery services (Google Fonts, jsDelivr, unpkg, Carto map tiles, Photon address search) — these load fonts, scripts, map tiles and address suggestions, and receive standard technical request data such as your IP address." %}

{% trans "Worker profile information (name, photo, profession) is visible to employers on the platform, and job postings (including the contact phone number and location) are visible to workers." %}

{% trans "4. How long we keep it" %}

{% blocktrans trimmed %} We keep your account and profile data for as long as your account exists; we do not delete it automatically. SMS verification codes are kept for a maximum of 5 minutes. You can request deletion of your account and data at any time, as described below. {% endblocktrans %}

{% trans "5. Your rights" %}

  • {% trans "You can view and edit your profile information at any time from the profile page." %}
  • {% trans "You can request a copy of the data we hold about you." %}
  • {% trans "You can request deletion of your account and all associated data." %}

{% trans "6. How to delete your account and data" %}

{% blocktrans trimmed %} Send an email to support@intask.uz stating the phone number you registered with. We will verify that you control that phone number and then delete your account together with your profile, uploaded photos and certificates, job postings and job applications. {% endblocktrans %}
